Check and update the records for the cattle on your holding in England.

This service replaces Cattle Tracing System (CTS) Online.

Applies to England

  • Guidance for Northern Ireland
  • Guidance for Scotland
  • Guidance for Wales

You can:

  • register a calf birth
  • report a cattle birth
  • report cattle, bison or buffalo moving on or off your holding
  • check the details of individual animals
  • correct something you have already reported

Registering takes around 5 minutes.

Before you start

To use this service you need a County Parish Holding (CPH) number.

If you do not have a CPH number yet, you'll need to set up as a livestock keeper first. When you're set up, you can create your account.

You can’t register for this service if you’re in the UK illegally.

Sign in or create your account

If you already have an account, you will be able to sign in, or create one if you haven't already.

Other ways to report

You can also report a birth, movement or death by phone or post, or using farm software. The rules and deadlines are different for each task.

Find out how to:

  • register a calf birth
  • register a cattle birth
  • register a cattle death

Get help with this service

If you need help using this service, contact BCMS. If you need help getting a CPH number, contact the Rural Payments Agency.
